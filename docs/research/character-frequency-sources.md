# Character frequency source recommendation

Checked 2026-11-08 against primary sources using shell HTTP downloads; inspected actual data, not third-party mirrors.

## Decision

**Use SUBTLEX-CH's `SUBTLEX-CH-CHR`, ordered by descending `CHRCount`, as the default frequency backbone.** Its dialogue-oriented exposure is a better match for conversationally fluent Mandarin adults learning literacy than Jun Da's formal written corpus. Use Jun Da Modern as a secondary written-language cross-check, not the bundled default.

Frequency should guide target selection, not dictate every word in a story: reuse familiar spoken vocabulary, introduce characters in meaningful words, and allow natural narrative exceptions. Neither source establishes an optimal literacy-learning sequence for this particular audience; the fit recommendation is an inference, not a demonstrated teaching outcome.

## SUBTLEX-CH — recommended; public vendoring permitted with attribution

- **Corpus:** Cai & Brysbaert (2010), [official paper](https://doi.org/10.1371/journal.pone.0010729): 46,841,097 character tokens, 5,936 distinct characters, 6,243 film/TV contexts. Counts include characters inside multi-character words—not merely single-character words. Subtitles approximate everyday exposure, but are scripted/translated entertainment, not a representative sample of spontaneous Mandarin; names, genre and translation biases remain. This is also an older corpus.
- **Verified download:** [paper's Files S1 ZIP](https://journals.plos.org/plosone/article/file?type=supplementary&id=10.1371/journal.pone.0010729.s002). It contains `SUBTLEX-CH-CHR`, `SUBTLEX-CH-WF`, and `SUBTLEX-CH-WF_PoS`; use **CHR**, not the word lists. The character file is tab-separated, decodes with `gb18030`, and has two metadata lines before its header. Verified 5,936 one-character rows, already descending by count, summing to 46,841,097. Fields include raw count, frequency/million, contextual diversity and logarithms. Keep contextual diversity as useful supporting information.
- **Script:** the paper collected subtitles from mainland sites providing Simplified Chinese. Nevertheless, the file retains traditional forms separately: `这` 633,842 / `這` 1; `后` 109,915 / `後` 573. It is simplified-oriented, **not guaranteed simplified-only or fully variant-merged**. Preserve the original ranking/provenance; review/filter variants for a simplified curriculum. Any conversion/merging must be explicit and reranked, especially for ambiguous mappings such as 發/髮 → 发.
- **Actual reuse evidence:** the abstract says “freely available for research purposes,” which alone would not authorize public redistribution. Crucially, the official [PLOS dataset record](https://plos.figshare.com/articles/dataset/SUBTLEX_CH_Chinese_Word_and_Character_Frequencies_Based_on_Film_Subtitles/143218), also available as [API metadata](https://api.figshare.com/v2/articles/143218), explicitly declares **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)** and includes `Files_S1.zip` ([direct download](https://ndownloader.figshare.com/files/421463)). Its bytes match the paper's ZIP: MD5 `b2152c246d69c7c2b0bc01b67369a345`. This is dataset-level licensing evidence, not an assumption that the article's license automatically covers external data.
- **Public GitHub:** yes, on that explicit CC BY basis, including adapted UTF-8 tables. Credit Qing Cai and Marc Brysbaert, cite the 2010 paper and dataset, link the license, retain notices and identify transformations. Do not present the data as MIT/CC0 or assume permission extends to the underlying subtitle texts. The [Ghent homepage](https://crr.ugent.be/) currently reports reconstruction; use the publisher-hosted files rather than relying on old lab URLs.

## Jun Da Modern — useful cross-check; public vendoring unclear

- **Corpus:** the author's [2004 paper](https://lingua.mtsu.edu/academic/dajun-4thtech.pdf) documents 193,504,018 modern character tokens and 9,933 distinct characters; approximately 55% informative / 45% imaginative writing. “Modern” means texts published from 1911 onward, collected online in 1997–2003—not exclusively contemporary conversation. It explicitly includes only formal Modern Chinese and makes no effort to collect BBS/email-style informal writing. Better suited to broad written-reading coverage than dialogue-led stories.
- **Verified downloads:** [official index](https://lingua.mtsu.edu/chinese-computing/statistics/), [Modern list](https://lingua.mtsu.edu/chinese-computing/statistics/char/list.php?Which=MO), [tab-delimited data](https://lingua.mtsu.edu/chinese-computing/statistics/char/download.php?Which=MO), [Excel](https://lingua.mtsu.edu/chinese-computing/statistics/char/CharFreq-Modern.xls). Select **MO**, not combined Classical+Modern **TO**. Verified 9,933 text rows, decoding with `gb18030`, with rank, character, raw count and cumulative percentage; counts sum to 193,504,018. Data date: 2004-03-30. Extra Pinyin/gloss fields have additional third-party provenance, including CEDICT.
- **Script:** predominantly simplified-oriented, but no explicit normalization policy was found. Distinct traditional forms survive: `后` 570,764 / `後` 5,938; `这` 1,552,042 / `這` 483. GB encoding does not prove simplified-only content.
- **Terms:** the author's [copyright notice](https://lingua.mtsu.edu/chinese-computing/copyright.html) retains copyright, permits “research and teaching/learning purposes only,” and requires “prior written permission” for commercial use. This is **not a permissive open-data license**. Public redistribution, adaptation and downstream reuse are not expressly granted. **Do not vendor the table or a derived ranking into public GitHub without written permission** covering that use; citation alone is insufficient. Links are the safer default.

Leeds/BCC were not needed to choose between these verified character datasets; no alternative licensing or download claims are made here.
