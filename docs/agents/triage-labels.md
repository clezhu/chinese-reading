# Triage labels

Use these exact label strings when a skill refers to a triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Needs initial review |
| needs-info | needs-info | Waiting for more information |
| ready-for-agent | ready-for-agent | Clear enough for an AI agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Edit the GitHub label column if the repository's vocabulary changes.
