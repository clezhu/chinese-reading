Specific contextual decisions checked:

- 尼克 ní kè and 安尔 ān ěr are names. 罗 luó is a surname.
- 长官/队长 use zhǎng; 教官/指教 use jiào, while teaching someone uses jiāo.
- 乐 is lè for delight/laughter, yuè in 音乐. 好奇 uses hào qí.
- 大夫, the doctor in the comic play, is dài fu; 护士 is hù shi.
- 重新 is chóng xīn; 重要 is zhòng yào; 度过 is dù guò; 了解 is liǎo jiě.
- 信息 is xìn xī, while 消息 is xiāo xi. 认识 is rèn shi, 告诉 is gào su,
  主意 is zhǔ yi, 东西 is dōng xi, 时候 is shí hou and 先生 is xiān sheng.
- 爱人 uses ài ren for spouse, including the checkpoint. 哥哥/弟弟 use neutral
  second syllables; underlying third-tone spelling is retained.
- 一/不 follow the documented contextual convention. Potential-complement 不
  is neutral in forms such as 救不了 and 说不清. Reduplicated verbs use authored
  neutral second syllables where appropriate; pinyin is never inferred at runtime.
- A textual 儿 remains a separate token/syllable; 这儿 is zhè + ér in this
  one-character token contract.
